# Balance Plan

Status: no reference numbers accepted

## Method

1. Record observed timing/range samples as observations, never copied constants.
2. Infer only distributions/relationships with controlled experiments.
3. Establish original baseline numbers that preserve intended pacing, not exact reference values.
4. Run deterministic scenario batches for win rate proxies, leaks, economy curve, build timing,
   enhancement impact, and entity concurrency.
5. Review deltas per content family.

## Gates

- three repeated early battles before any randomness claim;
- critical timings within ±15% only where observation confidence is at least 0.8;
- load benchmark at observed maximum concurrency +25%;
- no unexplained dominant option in the tested starter slice;
- balance changes never alter engine algorithms without a separate ENG card.
