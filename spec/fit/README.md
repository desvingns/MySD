# Fit Registry

After Gate 1, create one checklist per accepted state and one registry row per state/data-state
combination. Each checklist covers:

- route/overlay/battle-phase behavior;
- visible affordances and guards;
- key bounds in dp;
- masked structural visual comparison;
- transition timings;
- positive/negative data states;
- explicit deviations.

An accepted reference state without a row is a blocker.
