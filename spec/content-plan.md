# Content Plan

Status: Gate 1 pending

## Originality rules

All public content uses original names, silhouettes, palette, icons, lore, audio, prose, reward
numbers, enemy/building/unit families, and stage geometry. Reference evidence informs functional
roles and screen structure only.

## Schema families

Expected but not yet confirmed:

- campaign/stage definitions;
- buildings and production recipes;
- allied and enemy unit families;
- waves/boss modifiers;
- in-run enhancement pool;
- roster/loadout progression;
- technology DAG;
- economy/energy/sweep rewards;
- local service fixtures.

Each accepted family needs schema version, validation errors with field paths, stable IDs, replay
impact, save impact, and at least one invalid-content fixture.

## Delivery rule

Add one content family at a time with scenario tests, replay goldens, migration coverage, and a
balance report. Final counts wait for observed inventory.
