# Accessibility

- Minimum interactive target: 48×48 dp.
- Controls expose semantic labels in original MySD wording.
- Color is not the sole carrier of lock, affordability, damage, or claim status.
- Text supports Android font scale; clipping/overlap is checked at non-default scale.
- Reduced motion is a persisted profile setting. It removes nonessential transitions and repeated
  decorative motion without changing authoritative battle timing.
- System Back behavior and focus order are tested per accepted state.
- If the reference uses smaller targets, `deviations.md` records an intentional accessibility
  difference; visual-fit may compare placement but cannot require an inaccessible hit target.
- Canvas exposes one concise battlefield summary rather than an accessibility node per entity;
  build slots, hero skills, and actionable overlays remain separate semantic nodes.
- Selected, locked, claimed, affordability, wave, and terminal states have text/state descriptions.
  Wave/phase announcements use a polite live region; terminal announcements use an assertive one.
- Every route must reflow without clipped primary actions at Android font scale 2.0.
