# MySD SPEC board

This board mirrors the approved PHASE_03 implementation queue. The folder is the status:

- `backlog/` — approved runnable SPECs not started;
- `active/` — the single SPEC currently being implemented;
- `done/` — shipped or explicitly already-delivered SPECs with implementation links.

SPECs below are derived from `docs/implementation_plan/phases/PHASE_03_android_contour.md` and
must preserve the accepted semantic scope, Android-free deterministic game boundary, and public
safety rules in `AGENTS.md`.
